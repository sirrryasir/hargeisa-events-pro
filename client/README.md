# Client

Frontend application for Hargeisa Events Pro.

Canonical project documentation lives in the repository root:

- [`../README.md`](../README.md)

## Local Commands

```bash
npm install
npm run dev
npm run build
npm run start
```

## Notes

- Framework: Next.js App Router
- Auth: NextAuth Credentials Provider backed by the server API
- API base URL: `NEXT_PUBLIC_API_URL`
- Protected application routes live under `/dashboard/*`
