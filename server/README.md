# Server

Backend API for Hargeisa Events Pro.

Canonical project documentation lives in the repository root:

- [`../README.md`](../README.md)

## Local Commands

```bash
npm install
npm run dev
npm run build
npm run test
npm run data:import
npm run data:destroy
```

## Notes

- Framework: Express + TypeScript
- Database: MongoDB via Mongoose
- Auth: JWT Bearer tokens
- API prefix: `/api`
